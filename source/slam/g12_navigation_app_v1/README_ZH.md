## 已实现

- 完整冻结地图、66 点室外路线、室内 10m 路线、机器人位姿与轨迹。
- 每段可批量预设 **基础·敏捷 / 楼梯·敏捷 / 高台**，原厂 ID 分别为 `0x3002 / 0x3003 / 0x1002`。预设保存到 Orin 私有配置，带路线摘要及修订号。
- 人工可指定上述三种及 **基础普通 / 楼梯普通 / 低速 waypoint / 高速 waypoint**。普通模式原厂 ID 分别为 `0x1001 / 0x1003`，沿用原厂完整比例摇杆范围；普通与 waypoint 仅用于人工接管，不加入路线预设。
- 导航页有明确的 **路线预设 / 人工覆盖** 两种方式。每次「启动 / 恢复导航」成功后自动进入路线预设，接入段按最近未来目标所属段选择策略。点击基础、楼梯或高台即进入人工覆盖，跨路点持续生效，直到点击「路线预设」或再次启动导航；暂停本身保留选择。点击「人工覆盖」会固定当前策略。人工接管仍在独立页面使用七种策略。
- 自动路线跟随使用连续 Hermite 轨迹、速度前馈和三轴耦合 PID，同时输出真实 `vx / vy / wz`，官方速度接口为 `0x110002`，单位 m/s、rad/s，使用导航模式 `Mode=1`。巡航参考为 0.8 m/s，同一策略内中间路点只记录通过，不停车确认或重置 PID；策略变化处按下文短暂停车切换，整条路线终点收敛停车。导航、定位和网关不再另加速度、转速、加速度限幅，也不使用旧路线文件内的速度上限；物理速度原样交给所选原策略处理。没有按角度阈值切换“先转向、再前进”的控制阶段。
- 启动或恢复导航时，自动选择剩余路线中最近的前方目标点，生成当前位置到目标段的接入折线，到达后继续原路线。无需人工回到 I00 或旧路线起点；地图用紫色显示接入路径。已实际到达的点与自动接入跳过的点分别记录，暂停、人工接管或重定位后的恢复不会退回过去的目标。
- 人工接管读取 G12 实体摇杆；自动导航时明显推杆可接管，松杆后仍保持人工，必须明确恢复导航。人工官方策略沿用原运控 App 的 `Mode=0 / 0x100002` 比例摇杆接口，前后、横移、转向的 `-1～1` 输入原样发送，由策略决定运动响应。人工控制不再套用导航的 0.20/0.10 m/s 和 0.20 rad/s 限制。
- waypoint 使用原有相对路点输入及模型速度特性，**选择 waypoint 会暂停自动路线并进入人工控制准备**。它不是已标定的速度跟踪器，本版不把它用于自动速度闭环。
- 导航地图页直接提供「基础 / 楼梯 / 高台」三个按钮。切换先原地暂停约 0.5 秒，切换完成后自动继续；可以连续改选，以最后选择为目标。低/高速 waypoint 同样先暂停再切换模型；跨控制器保留已有站立交接。
- 点选附近重定位通过一次可用几何匹配即可生效，可取消搜索；重定位后保持暂停。
- 连续雷达里程计为导航主位姿，地图仅作平滑校正。地图短时失配、校正积压或自动重检索不再让新鲜雷达定位停走；全局路线偏移时由操作者重定位。短时配准失败保留雷达几何参考，运动预测与点云不一致时可由独立点云复核恢复；短暂观测间隙用已接受雷达运动估计衔接，并明确记录为预测。
- 重新规划可选择目标点、排除阻塞路段，从新鲜定位关联到现有路线走廊，生成预览，显示跳过的原路线点，确认应用后保持暂停。预设按原始边继承。

## 本次定位与进度调整

- 定位质量分为正常、降级可用和不可用。局部与地图配准共用可用性标准：重叠率至少 35%、最近邻中位误差不超过 0.35 m、几何条件比至少 1e-8；达到旧的较高指标时标为正常。迭代未收敛、IMU 预测偏差不再单独否决可用配准。降级结果仍参与导航，不额外限速。
- 人工点选重定位得到一次可用几何匹配即可生效，取消连续三帧准入。点选仍定义搜索区域，并非直接赋值位置。
- 局部参考失配时，可用地图位置参与局部匹配的初值计算；失配持续超过 0.8 秒且有可用地图观测时自动重建当前场景参考。实际运动仍由点云匹配产生，地图坐标系和路线进度保持。
- 地图备用定位的短暂处理间隔，可使用真实地图位移估计短期运动，最长到最新观测后 0.45 秒；预测不算实际到达。完全失效时保留最后显示位置和真实时间，不跳回更旧的局部位置。
- 「设置进度」从当前路线选一个点作为下一目标，允许前跳和回退。设置后暂停，启动时明确接入该点，不被最近点逻辑跳过；通过后沿原路线继续。手动跳过与实际到达分开记录。重新启动仍默认进入路线预设。

2. 用「开启点选」选择实际位置附近，按「在此附近重定位」。点选只是搜索候选，不直接设置真实位姿。
3. 「导航操作」选择室内或室外路线。「策略 / 分段 → 编辑分段预设」勾选一段或多段并保存三种官方策略之一。
4. 点击「人工接管」立即进入独立人工控制页并自动启用摇杆，无需另按启用按钮。人工可选七种策略，选策略即提交控制请求。已站立时直接使用实体摇杆；需要起立时按一次「起立」，完成后自动接收摇杆。休眠时按「唤醒」，沿用原厂 App 的 `Sleep=false` 指令。MONITOR 模式下仍提供影子试控。

6. A 键进入人工控制页；B / D：停止并锁定；C：起立。自动导航中推杆触发接管时也进入人工页。仅处理新按键边沿，重连不重放动作。D 的停止电平持续有效。
7. 自动导航：完成起立并获得有效定位，返回地图选择路线、设置路段策略，再按「启动 / 恢复导航」。系统直接规划接入最近的前方目标，无需另开预览或先移到路线起点；接入段继承目标所属路段的策略。「重新规划」仍可用于人工选择终点和排除指定路线边，预览应用后再恢复导航。
8. 「停止」保留站姿/零输入；「阻尼」为明确卸力操作，两者不同。

人工输入由独立线程持续发送，不与地图刷新和操作请求排队。人工控制只使用实体摇杆输入，不依赖导航心跳、定位或雷达放行，也没有 `FRESH_G12_STICKS_REQUIRED` 或回中启用门槛。输入暂缺时发送零输入，保留人工控制意图；数据恢复后自动继续。进入后台、实际控制链路中断或重定位会停止输出。自动导航继续使用定位和障碍物检测。人工比例与导航物理速度分别标记单位，接管和恢复导航时自动切换对应输入接口。
