# 连续导航鲁棒性更新（2026-09-19）

## 改动目的

数据缺失时优先使用仍有效的冗余信息维持低速跟随，而不是把每次质量降级都变成人工重新 ARM。程序存活、任务进度、运动许可分别管理；不能用“进程没退出”证明机器人可以继续走。

本轮仅修改独立 native_navigation_v1；冻结 V2、地图、外参、原路线和本体网关协议/验收条件均不改变。按 access-agx-orin 的独立 wym 环境流程，先在暂存目录测试，保留旧源码再部署。

## 已实现

1. 不因连续性修正计数变化就撤销许可，实际位姿跳变仍检查。
2. 通过连续、同 epoch 的 VIO 与 IMU 实测增量估算身体运动；对小幅地图校正做有界融合，原始地图观测不删除、时间戳不重写，融合残差占用走廊余量。
3. 地图匹配短缺时增加实测里程计接续：地图年龄最多 1.20 秒、累计里程不超过 0.15 米，上限 0.03 m/s；只有 VIO/IMU 连续且一致才允许。纯恒速预测仍最多 0.55 秒。缺失 VIO、共同 IMU 缺口、epoch 跳变或明显不一致不能获得额外时间。
4. 独立选择 VIO 和 IMU 都已有数据的共同时间端点。较新的 VIO 不能要求还没收到的 IMU 外推；缓存接续保留原观测/积分时间，预算随年龄增加。
5. 坏包、重复包、非有限数隔离；不把一条异常消息变成进程退出。日志限额，磁盘写失败降级重试。
6. 证据不足时才 HOLD，保持目标点与当前许可并持续发零；重新稳定后受约束地续行。STOP、控制权丢失、网关/定位身份变化不自动 ARM。
7. 网关断连后台退避重连，任务不退出、不重放旧动作。执行进度原子保存，`--resume-checkpoint` 只恢复进度、不恢复运动许可。

## 验证证据与边界

- 原 44 项回归全部保留；新增路线状态机、真实 loopback TCP、缺帧、坏时间戳、VIO/IMU 缺口与不一致、地图噪声、检查点、日志失败等测试。最新完整测试计数以 `results/software-validation-*.json` 为准。
- 理想运动学模拟：室内 21 点按序完成，注入 5 次完整感知失效后恢复，125.12 秒完成；这是合成模拟，不是实机到点精度。
- 生产 ROS 入口在无网关端口运行 8 秒，持续零输出并自动重试，正常退出，不再因连接拒绝而结束任务。
- 实传感器同输入比较：`results/paired-readonly-20260919-221858/summary.json`。总计 140.22 秒，排除前 20 秒后 5983 个比较样本。旧/新超短步位姿跳变阈值次数为 **72 / 2**；LOST 为 **221 / 216**，仍有真实过期，不能只报告平滑改善而隐去失效。
- 后续增加只在测试中暂停地图锚点更新的缺口注入。IMU/VIO 仍来自真实接收；两套算法接收相同输入缺口。具体通过与剩余失效见追加结果，不能将软件注入说成实机行走。
- 最终接续优化后同输入注入测试：`results/paired-readonly-20260919-223017/summary.json`。总计 90.21 秒，排除前 20 秒后 3499 个样本。旧/新位姿跳变超限 **53 / 1**，LOST **237 / 119**。其中 0.8 秒地图输入暂停：旧逻辑 25 个 LOST，新逻辑对应 25 个 ODOM_BRIDGE、整个暂停窗口 **0 LOST**；1.6 秒暂停：新逻辑接续 32 个样本后仍有 28 个 LOST，保持 1.20 秒地图年龄预算，没有无限外推。整体剩余失效包含缺新鲜 IMU、地图候选未确认或年龄已超预算。
- 缺口接续早期版本在实传感器上未达到预期，之后修正共同端点选择，并复用原时间端点避免重复重积分阻塞回调。没有通过放宽 IMU 80 ms 时效来掩盖失效。中间试验同样保留，最终数字以上述最终运行目录为准。
- 旧基线源码保存为 `results/baseline-robust-timing-20260919.py`，SHA256 `8549a9100b7ef588acf7addf0226d98ba0790b8e78f3877b214e00caf17699c2`。早期探索测试及未通过记录保留在暂存目录，不改写历史报告。
- `results/reassociation-audit-20260919.json` 是旧健康日志的位姿/计数审计，不是原始 IMU/VIO 回放；没有缺失原始数据就不能声称新接续能挽救旧日志中的每次 LOST。

所有本轮现场测试均不发布定位消息，不启动运控、不发送姿态/速度指令。测试结束后关闭本轮启动的传感器。没有改写 `acceptance.json`，没有把软件测试记为硬急停或原厂接收端停车验收。

目前只能确认软件与短时只读对比的改善；还不能保证动态长程不中断、定位绝对准确或路线已实机闭环通过。融合/接续预算是工程试验边界，不是经外部真值标定的协方差。
