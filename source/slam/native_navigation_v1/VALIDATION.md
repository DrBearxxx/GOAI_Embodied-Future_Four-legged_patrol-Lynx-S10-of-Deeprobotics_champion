## 本轮发现并修正

1. 快循环在 Windows 低分辨率 monotonic 时钟上重复读取同一 tick，不能被当作时钟倒退；仍拒绝真正倒退，并保留原有效期。
2. 发起新 POLL 会更新服务端票据，客户端立即作废旧未用票据，避免旧票据与新请求交叉导致误锁止。
3. run-id 检查会更新内部身份，首轮发现异常时先锁止，避免第二次基础检查把该异常消费掉。
4. 完整路线 + TCP 的 25 Hz 测试覆盖了握手与持续运行，不仅验证单包发送。
