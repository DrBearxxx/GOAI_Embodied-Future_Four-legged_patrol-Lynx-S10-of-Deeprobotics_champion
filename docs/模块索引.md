# 模块索引

以下路径均相对 `source/slam/g12_navigation_app_v1`。

| 文件或目录 | 职责 |
|---|---|
| android/src/com/wym/s10nav/MainActivity.java | 地图、操作页、策略、实体摇杆和请求调度 |
| android/src/com/wym/s10nav/RouteDisplayCache.java | 按服务与地图隔离的离线路线缓存 |
| runtime.py | ROS 接收、认证接口、主循环、日志和组件连接 |
| lightning/bridge.py 与 lightning/service.py | 传感器适配、Lightning 成组生命周期与 epoch |
| lightning_odometry.py | IMU 系转机体系、时间映射、实测运动计算 |
| continuous_pose.py | 里程计历史、地图对齐、自动平滑融合、预测标记 |
| automatic_localization.py 与 worker.py | 后台局部地图匹配、异步观测输出 |
| seed_matcher.py 与 localization_quality.py | 人工附近搜索与几何可用性分级 |
| registration_motion.py 与 registration_log.py | 点云去畸变、匹配输入与结果记录 |
| planning.py | 路线预设、图上重规划、最近未来目标接入 |
| navigation.py | 进度、轨迹跟踪、临时点及运行状态 |
| trajectory.py 与 pose_pid.py | Hermite 轨迹、速度前馈、耦合 PID 和航向参考 |
| mission.py | 自动、人工、暂停仲裁；策略覆盖；操作请求 |
| route_calibration.py 与 route_geometry.py | 点位草稿、应用、撤销与校正点几何 |
| route_recording.py 与 temporary_waypoints.py | 新路线手动标点录制及地图临时队列 |
| obstacle_evidence.py | 前向障碍证据与楼梯高台支撑面处理 |
| gateway_bridge.py 与 backend | 单一控制出口、原厂和 waypoint 策略、反馈与故障恢复 |
| start_all.sh 与 start.sh | 恢复网络、传感器及服务启动复用 |
| test_*.py 与 backend/test_*.py | 软件契约、融合、路线、策略和恢复测试 |

依赖目录 `route_navigation_v1`、`indoor_navigation_v1`、`native_navigation_v1` 保持并列结构，由 `paths.py` 自动发现。地图与冻结依赖的 manifest 校验属于文件一致性检查，不是定位置信度限制。`source/lightning/runtime-source` 保留选用算法及构建依赖的许可证和原始来源信息。
