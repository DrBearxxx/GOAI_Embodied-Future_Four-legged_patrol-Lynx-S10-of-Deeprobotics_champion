Orin 使用 Ubuntu 24.04 ARM64、ROS 2 Jazzy 和已有 S10 运行环境。本包保存导航完整源码、地图依赖、Lightning 编译源码及已验证的 1.32 到 1.33 增量。不是适用于所有历史版本的通用覆盖安装器。原差量部署脚本保留哈希兼容检查；若现场源码已变化，应先比较差异，不直接复制整个源码目录。

2026-09-22 部署记录显示 1.33 已安装；2026-09-26 仅整理本机资料，没有重新核实机器人当前状态。已有 1.33 时正常启动即可，不必重复升级。

## 启动已有服务

```bash
bash /home/wym/s10_navigation_app_v1/start_all.sh
```

脚本恢复 G12 主机回程路由，启动传感器接收，再启动或复用运控网关、Lightning 和导航主服务。冷启动选择室外完整路线；服务启动本身不发起导航或起立。需要管理员权限恢复路由时，使用设备现有 sudo 方式，脚本不保存口令。

G12 默认访问 `http://10.21.33.102:18894`；网关仅监听 Orin 回环 `127.0.0.1:18895`。G12 最近确认地址为 `10.21.41.12`，回程经 `10.21.33.103` 的 `end0`。若 G12 IP 改变，设置 `GOAI_G12_IP` 后启动。Windows USB SSH 中继仅用于运维，不是 App 正常运行的数据通路。

只读检查：
```bash
python3 /home/wym/s10_navigation_app_v1/startup_status.py
python3 /home/wym/s10_navigation_app_v1/lightning/service.py status
```

`goai-navigation`、`goai-nav-gateway`、`goai-navigation-lightning` 是不同 tmux 会话。启动脚本已用精确会话名处理，避免将 Lightning 误认为主导航已启动。

## 已有 1.32 环境升级到 1.33

将整个包复制到独立目录，先校验清单，再在 Orin 对增量执行隔离测试：
```bash
python3 tools/verify_delivery.py
cd release/orin-auto-map-1.33
python3 deploy_auto_map.py
```

不带参数时只在副本执行导航测试，使用 ROS domain 92。原在线服务不变。`evidence/auto-map-20260922/validation.json` 是历史证明，未复制到可执行增量根目录；本次升级需由上面的命令生成当前环境验证结果。

在 App 暂停并结束当前控制后，执行：
```bash
python3 deploy_auto_map.py --deploy
```

脚本检查当前暂停、网关未启用和零输出，保存实际路线进度及临时队列，只停止并替换导航主进程，保留 Lightning 和运控网关。该检查用于软件替换，不在 App 操作中新增确认流程。部署完成保持暂停。初始地图对齐缺失时在 App 点选附近进行真实几何重定位，再按需恢复导航。

脚本支持应用过程异常时自动恢复备份源码与暂停进度，不提供已完成部署后的通用 `--rollback` 参数。历史 1.33 升级备份记录为 `/home/wym/s10_navigation_app_v1/logs/pre-auto-map-3xnt_0bq`；回退前应以实际备份和当时运行状态为准，不能用旧进度覆盖后续校准。

## Lightning 运行时重建

已有正常运行时无需重建。需要重新编译时，在 Orin 执行：
```bash
cd source/lightning
bash build_lightning.sh
```

脚本使用原 `runtime-manifest.json` 校验源码，编译至 `/home/wym/s10_lightning_runtime_v1`，不下载或安装系统依赖。需预先具备 `/home/wym/s10_slam/env.sh`、ROS Jazzy、colcon、CMake、Eigen、PCL、yaml-cpp 和 Python 导航依赖。以构建脚本及 CMakeLists 声明为准。归档的 ARM64 二进制校验值在 `evidence/lightning-build-20260922/build-provenance.json`；编译器和依赖变化后，新二进制哈希可能不同。

## G12 APK

```powershell
adb devices
adb install -r release/android/GOAI-Navigation-1.22-offline-route.apk
```

APK 已按原证书签名。`-r` 保留原 App 数据；不卸载、不清空配对。新设备需要沿用既有独立配对流程，本包不含认证密钥。1.33 服务更新不要求重装 APK。

源码构建入口为 `source/slam/g12_navigation_app_v1/build_apk.py`。该脚本保留原机器 JDK、Android SDK 和 Kotlin 缓存绝对路径，换机器需调整。覆盖安装必须使用原签名私钥，本包仅提供已签名 APK；不要将脚本生成的新开发证书误当成原签名。
